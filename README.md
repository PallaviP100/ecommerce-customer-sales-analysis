
# E-Commerce Customer Behavior & Sales Intelligence

## Overview

Analyzed e-commerce sales and customer data to identify sales trends, top products, customer behavior, and customer segments.

## Tools

Python, Pandas, SQL, SQLite, Scikit-learn, Power BI, DAX

## Key Analysis

* Analyzed total orders, customers, products, and monthly sales
* Identified top-selling products and high-value customers
* Analyzed revenue by category and state
* Created customer features such as Total Spending, Number of Orders, and Average Order Value
* Used K-Means clustering for customer segmentation
* Built an interactive Power BI dashboard

## Dataset

The original dataset CSV file is **not included** in this repository. The repository contains the analysis code, SQL queries, dashboard, and project documentation.

## Key Skills

SQL • Python • Data Cleaning • EDA • K-Means Clustering • Power BI • DAX • Data Visualization
